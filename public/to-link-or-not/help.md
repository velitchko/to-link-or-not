# Help

## General

**How do I select an answer?**
Click on one or more nodes in the diagram. Selected nodes turn green. For tasks that ask for a single node (T1), clicking a different node changes your selection. For tasks that ask for multiple nodes (T2, T3), each click toggles that node on or off.

**How do I submit my answer?**
Click the **Submit Answer** button below the diagram. The button is disabled until you have selected at least one node.

**Can I change my answer before submitting?**
Yes — click any node again to deselect it, or click a different node, before pressing Submit.

---

## Task Types

**T1 – Hub identification**
Select the single node you believe has the most connections (highest degree).

**T2 – Common neighbors**
The two orange nodes are given. Select all nodes that are directly connected to *both* of them. Orange nodes themselves are not selectable.

**T3 – Community detection**
Select all nodes that form one distinct, tightly-connected cluster. There is no single correct answer — responses are analyzed qualitatively.

## Link-Rendering Styles

| Style | What You See |
|-------|-------------|
| **Traditional** | All connections drawn as lines at all times |
| **No Link** | No connection lines — layout only |
| **On-Demand** | Connections for a node appear when you hover it |
| **Stubs** | Short partial lines extending from each node toward its neighbors |
